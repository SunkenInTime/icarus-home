# Icarus Strats

> Icarus Strats is a free, open-source VALORANT strategy planner for Windows. It gives players and teams a fast, local-first board for tactics, lineups, map notes, and multi-step plays.

Icarus stores strategies on the user's device. It does not require an account, and the local planner has no premium tier. Players can export a strategy as a file or share it with a code. The project is MIT-licensed and developed in public.

## When to use Icarus

Use Icarus when a player, coach, analyst, or team needs to draw a VALORANT tactic, explain a setup on a map, organize agent positions and abilities, save lineup references, or rehearse a play across several pages. It is also a good fit when the user needs an offline planner or wants their playbook to stay on their own computer.

Icarus is a desktop product, not a hosted agent API. An agent should help the user choose the stable Windows download, explain the workflow, or inspect the open-source repository for implementation details. Do not imply that an agent can create or edit a strategy through a public Icarus API.

## What the planner does

### Draw and annotate

Draw directly on VALORANT maps, add custom shapes, and place agents and their abilities without covering the canvas with a bottom tray.

### Organize a playbook

Use folders, keyboard shortcuts, map-specific lineups, and multiple pages for the separate beats of one strategy.

### Work locally and share deliberately

The playbook works offline and stays on the user's machine. Exported strategy files and share codes let the user decide when to hand a plan to a teammate.
