# Save Valorant lineups in Icarus

> Icarus Strats is a free, open-source VALORANT strategy planner for Windows. It saves lineups on the map: where the player stands, where the ability lands, and a YouTube clip, screenshots, and notes for each throw.

In the Windows app, lineups save to the user's computer and work offline, with no account. Signing in is optional. Strategies the user moves to the cloud, lineups included, sync across computers and to the web version (beta), and teammates can edit them live. Signing in doesn't upload the local library on its own.

## Save a lineup

1. Press G, or click Add Lineup in the sidebar.
2. Drag the agent to the spot the player throws from.
3. Drag the ability to where it lands, then press Next.
4. Add a name, a YouTube link, screenshots (pasting from the clipboard works), and notes.

## Find lineups on the map

One standing spot can lead to several landings, and one landing can be reached from several spots. Clicking an agent's spot lists every lineup thrown from it. Clicking an ability lists every lineup that lands there. Each lineup opens its clip, screenshots, and notes.

## Share lineups with a team

Lineups belong to a strategy, next to the plays they support. Sharing the strategy with a code or an `.ica` file gives teammates every lineup in it. Signed-in teammates can edit a cloud strategy together live and see who is changing which lineup.

## Limits

- Icarus stores the lineups a user or their team saves. It is not a public lineup database.
- The app runs on Windows. The web version runs in a browser, needs a sign-in and a connection, and works with cloud strategies only.
